# mi349-first-github
This is my very first webpage, deployed using GitHub Codespaces.

This lab is meant to introduce the fundamentals of deploying a webpage using HTML, GitHub, GitHub Codespaces, and Netlify.

I learned to create GitHub codespaces, create HTML files (capitalization matters!), stage and commit changes to GitHub, and deploy a site with Netlify.

In an effort to learn more about webpage design, I also looked into how to add metadata to the <head> of the HTML file to add more features and capabilities. Additionally, I learned how to add comments to an HTML file to document changes (the comment method for HTML files is different from the method I am used to for Python (#)).
Article used: https://www.w3schools.com/html/html_comments.asp
